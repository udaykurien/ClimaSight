# ClimaSight
## Instructions to run
Clone the repo
```bash
git clone https://github.com/yourusername/climasight.git
```
To install dependencies, run
```bash
npm install
```
in each of
```bash
ClimaSight/apps/web
ClimaSight/apps/api
ClimaSight/packages/types
```
To test, run
```bash
npm test
```
in
```bash
ClimaSight/apps/api
```

To start local dev servers for monorepo run
```bash
npx turbo dev
```
